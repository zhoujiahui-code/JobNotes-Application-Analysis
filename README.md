# JobNotes 求职投递全链路分析与智能匹配系统

## 项目简介

本项目围绕求职投递全流程，构建了从数据治理、多维度分析到可视化呈现、智能岗位匹配的完整链路。通过结构化管理投递数据，量化拆解各环节转化效率，并基于规则加权算法实现岗位精准匹配，为求职策略优化提供数据支撑。

## 核心功能

### 1. 全链路数据监控

整合 200 + 条全量投递数据，覆盖岗位信息、投递状态、薪资区间、地区、学历要求等多维度字段，可视化呈现全流程状态分布与月度投递趋势。

### 2. 投递瓶颈诊断

拆解投递各阶段转化与流失效率，定位简历初筛为核心流失节点，单环节流失率达 45%，明确投递策略的核心优化方向。

### 3. 岗位智能匹配

基于多维度规则加权算法计算岗位匹配度，覆盖技能、学历、城市、薪资四大维度，输出适配岗位明细，匹配准确率达 74%。

## 项目结构

```
JobNotes-Application-Analysis
├── Code/                     # 核心算法与分析脚本
│   ├── analysis_query.sql    # 多维度数据分析SQL查询脚本
│   └── MatchingAlgorithm.java # 智能岗位匹配算法（纯Java工具类，无框架依赖）
├── Dashboard/                # 可视化运营看板
│   └── JobNotes_Full_Funnel_Application_Analysis_Dashboard.pdf
└── Data/                     # 数据模型与测试数据
    ├── schema.sql            # MySQL数据表结构定义
    └── test_data_sample.sql  # 测试样例数据（可直接导入）
```

## 技术栈

- 数据存储：MySQL 8.0
- 算法实现：Java 原生工具类（无第三方框架依赖）
- 可视化：FineBI
- 数据处理：SQL 聚合分析、正则文本清洗

## 核心亮点

1. **数据治理能力**：通过正则匹配实现非标准薪资文本的结构化转换，覆盖 95% 以上招聘场景薪资格式，统一输出数值区间。
2. **深度分析能力**：基于 SQL 多维度聚合计算，拆解投递全链路转化漏斗，精准定位核心流失节点，输出可落地的优化方向。
3. **规则算法设计**：采用多维度加权匹配模型，权重可根据求职策略灵活配置，支持四大维度的量化评分与排序。
4. **业务导向输出**：以业务分析视角构建看板，数据结论直接支撑决策，而非单纯的数据展示。

## 使用说明

1. **数据导入**
   - 执行 `Data/schema.sql` 创建数据表结构
   - 执行 `Data/test_data_sample.sql` 导入测试样例数据
2. **算法使用**
   - `MatchingAlgorithm.java` 为纯 Java 工具类，可直接调用静态方法
   - 支持薪资文本解析、区间重叠度计算、多维度加权总分计算
   - 内置测试用例，可直接运行 main 方法验证逻辑
3. **数据分析**
   - `Code/analysis_query.sql` 包含投递状态统计、转化率计算、多维度交叉分析等常用查询
   - 可基于表结构扩展更多维度的分析与统计
